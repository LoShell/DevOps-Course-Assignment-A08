# 实验复现证据

本目录只提交可审阅的文本证据，不提交 `build/`、`bin/`、对象文件或容器镜像。

建议按以下结构保存：

```text
evidence/
├── environment/
├── md-rd/
├── c0/
├── c1/
├── c2/
└── failures/
```

每份记录至少包含：执行日期、操作者、仓库 SHA、镜像标识、工作目录、完整命令、
退出码、关键输出和人工结论。服务器暂不可用或命令失败时，也应将失败原因和
处理过程放入 `failures/`。

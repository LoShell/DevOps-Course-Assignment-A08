# E7 协作流程

共同分支为 `a08/e7-validation`。统一实验基线 `E7_BASE_SHA` 为 `3a0ae35b27e783c480f66412b3e4f53802c6be68`，组长已完成八项门禁。收到分工后，各成员以这个 SHA 创建 `a08/<学号>/e7-validation`，用个人 PR 提交测试、验收记录和专项审阅。共同分支后续提交的分工和基线记录可直接在远程共同分支阅读。

组长汇总个人 PR 并执行集成验证。随后在现有仓库完成 `main` 正常 CI、分支保护核对、演示 PR 失败及合并拒绝、同一 PR 修复后通过并合并。演示 PR 单独从当时的 `main` 创建。

执行步骤见 [操作指南](OPERATION_GUIDE.md)，个人测试及验收条件见 [测试计划](TEST_PLAN.md)，交付分工见 [个人贡献](CONTRIBUTIONS.md)。

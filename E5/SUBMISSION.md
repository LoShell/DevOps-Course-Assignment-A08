# E5 独立提交检查表

E5、E6 分别上传。以下根据整理手册核对内容，不推定平台规定的名称、格式、上传主体或大小限制。

## 报告与贡献

- [ ] 仓库地址、A08、A 轨道、姓名与学号明确。
- [ ] docs/e5-a.md 汇总 E5，各人的命令、环境、实际退出码和结果有记录。
- [ ] 人工 MD/RD 表、成功读取与目标归属、Make 声明均有真实 PID/文件/行号依据。
- [ ] 说明教学参考来源、本人贡献、与论文机制及规模的差异。
- [ ] 运行完整 SHA 与后续文档提交 SHA 分开记录，未提交差异如实说明。
- [ ] 个人代码或分析修改、提交和 PR 可追溯。

## 每人的证据

- [ ] 实际输入副本：main.c、config.h、unused.h、Makefile。
- [ ] 完整 trace/、make-db.txt、build-stderr.log、program-output.txt 和本次其他产物。
- [ ] invocation.json、source-commit.txt、service-container-id.txt 和完整 runner/。
- [ ] 对应镜像构建、工具版本和服务测试记录；镜像代码与实验版本已核对。
- [ ] E5 入口退出 0、程序输出 1；缺失项或失败记录单列，不冒写通过。

## 归档与上传

- [ ] Git 保存源码、报告和索引，work/ 独立归档，不强制加入 Git。
- [ ] E5 归档包含报告、必要源码、实际输入和全部原始证据，不以 E6/E7 替代。
- [ ] 排除 .git、真实 .env、私钥、认证文件等无关或敏感材料。
- [ ] SFTP 下载到电脑并解压抽查，记录服务器与电脑保存位置。
- [ ] 平台截止时间、上传主体、格式、命名、附件和大小限制已核对。
- [ ] E5 上传状态已确认；E6 另行提交。

依据：本地 Lab/lab5 的 A 组 E5 手册及提交与验收手册。
两次作业分开上传由组长确认；其余平台格式待补充。本表不是新增教师要求。

## 3. 结果解释

baseline 运行版本为 `aff4eba7dca7a09a372d1264375d9fe9cd11354f`。原始检测退出码为 1，精确发现两项差异：

- `main.o` 的实际图中读取了 `main.c` 与 `config.h`，而 Make 声明为 `main.c` 与 `unused.h`；
- 因此遗漏依赖 MD 为 `config.h`，冗余依赖 RD 为 `unused.h`；
- `app` 的实际依赖和声明依赖均为 `main.o`。

原始检测的 `findings.json` 中，`config.h` 的成功读取证据为 `trace/t.15` 第 579 行；`main.o` 输出证据为 `trace/t.16` 第 23 行。`unused.h` 的冗余声明证据来自 `make-db.txt` 第 1053 行。

修复复检使用独立证据副本中的 Makefile，不修改 Git 工作区。修复前 Makefile 输入哈希为 `fd1dcd76a0bd9678351a1503941a5a875351455d4a6879e76af0af0b6c64772f`，修复后为 `128069c949b0239e3377f320d51498c2b37a317c602d8755d573a283e1f400ae`。校验结果为 `passed: true`、`before_findings: 2`、`after_findings: 0`，且 `changed_inputs` 只有 `Makefile`。

# E6 提交清单

## 个人成果

- [ ] 仓库地址、轨道、学号、实验日期、运行 SHA 与个人提交。
- [ ] 按教师模板填写个人报告与验收 CSV。
- [ ] 原始检测精确两条发现，status=SUCCEEDED，clean/build=0，入口1。
- [ ] 修复后 findings=[]、入口0，校验 passed=true 且只有 Makefile 输入哈希变化。
- [ ] 两图、进程、报告、全部 trace、Make 数据库、输入副本、命令与日志。
- [ ] 新增测试及机制说明、个人代码 SHA、修改后重建和再次 E6 的日志。
- [ ] 每条发现可追溯原始文件和行号。
- [ ] 构建与运行镜像 ID、版本、即时退出码记录。
- [ ] 归档下载至电脑，哈希核对；最终包包含定稿报告与源码。

## 小组成果

- [ ] 四项测试审阅合并，公布集成 SHA，测试数按实际收集结果核对。
- [ ] 至少两人同集成版本原始证据对照。
- [ ] 汇总个人贡献和 PR，完成组长整合报告。
- [ ] E6 独立打包，平台文件名、格式、截止时间和上传主体已核对。

work/ 独立备份，Git 保存源码、测试、报告和索引。E6 提交包含 E5 人工结论的必要引用。

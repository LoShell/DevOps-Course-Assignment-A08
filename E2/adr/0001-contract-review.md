# ADR-0001：采用外部契约引用和独立评审记录

- 状态：Accepted
- 日期：`2026-09-20`
- 决策人：A08 与 B08 配对成员

## 背景

B08 已经编写 E2 接口契约和请求、结果样例。A08 需要完成配对评审，同时
清楚区分双方文件贡献，并为后续 E3 实现固定契约版本。

## 决策

1. B08 仓库作为接口契约和样例的来源。
2. A08 不复制 B08 整套文件，而是记录仓库地址和固定 Commit SHA；本次评审固定在 B08 Commit `2c1b15332456410b74679d479094406fb7e183aa`。
3. A08 在独立仓库保存解释、评审、Backlog、AI 使用和贡献记录。
4. 双方通过各自仓库中的评审文档记录接口结论。
5. E3 以双方确认的固定版本为依据，不直接依赖 B08 的 `main` 分支。

## 影响

- 双方文件作者和贡献边界清楚。
- A08 仓库可以在 E3 继续独立开发。
- B08 后续修改不会自动改变 A08 已确认的契约版本。
- 契约发生变化时，需要双方重新讨论并记录新版本。

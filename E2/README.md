# A08 E2：需求与接口契约评审

本目录保存 A08 对 B08 E2 接口契约的评审成果。

B08 负责接口契约、OpenAPI、Schema 及请求和结果样例的编写；A08 不声明
这些文件的作者贡献。A08 负责解释样例、提出评审意见、确认交接方式，并
记录 Backlog、设计决定、AI 使用和个人贡献。

## E2 验收对应

| 课堂检查项 | A08 证据 |
|---|---|
| 配对组能解释同一份请求和结果 | `review/` 和 `A08_REVIEW.md` |
| 有接口样例 | `CONTRACT_REFERENCE.md` 指向 B08 固定版本样例 |
| 有 Backlog 和设计记录 | `BACKLOG.md` 和 `adr/` |
| 个人贡献与版本可追溯 | `CONTRIBUTIONS.md`、Commit 和 Issue/PR |

## 工作边界

- 本轮只做接口理解、评审和确认。
- 不实现 BuildChecker 或 EChecker。
- 不选择真实项目或 C0/C1/C2。
- 不生成真实 MD/RD 报告。
- E3 待办只记录在 Backlog，不在 E2 执行。
